\subsection{Сопоставление наблюдений с траекториями}
\label{subsec:association}

На кадре $t$ предсказанные положения активных траекторий
$\{\hat{\mathbf{p}}_i\}_{i=1}^{M}$ сопоставляются с наблюдениями
$\{\mathbf{z}_j\}_{j=1}^{N}$. Стоимость пары равна евклидову расстоянию
$c_{ij} = \|\hat{\mathbf{p}}_i - \mathbf{z}_j\|_2$. По матрице стоимостей
венгерский алгоритм~\cite{Kuhn1955} находит однозначное назначение с
минимальной суммарной стоимостью; пара принимается как сопоставление только
при $c_{ij} \le d_{\mathrm{match}} = [\cdot]$~пк, остальные пары разрываются.
Порог ограничивает допустимое смещение объекта за кадр и исключает прикрепление
траектории к далёкой детекции.

Сопоставленная траектория получает положение центроида наблюдения, счётчик
пропусков обнуляется. Несопоставленная траектория удерживается по предсказанию,
счётчик пропусков увеличивается; при более чем $M = [\cdot]$ пропусках подряд
траектория удаляется. Несопоставленное наблюдение инициирует новую траекторию.
Записи сопоставленных кадров помечаются статусом <<наблюдение>>, кадров
удержания --- <<предсказание>>.
